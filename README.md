## ゲームの操作方法

- Wキー：前進
- Aキー：左移動
- Sキー：後退
- Dキー：右移動
- マウス：左右の視点操作

## 実装した機能

- Unity Input Systemによるプレイヤー操作
- Rigidbodyによるプレイヤーの移動
- ColliderによるPlayerとItemの接触判定
- フィールド上に3個のItemを配置
- 複数のItemを配列で管理
- Item取得時にItemを削除
- 現在の取得数を「0 / 3」のように表示
- すべてのItemを取得すると「CLEAR」を表示
- プレイヤーが落下した場合、初期位置へ戻る
- マウスによる左右の視点操作
- カメラのプレイヤー自動追尾

## ゲーム画面

ゲーム開始時は「0 / 3」と表示されます。

フィールド上の3つのItemをすべて取得すると、
「CLEAR」が表示されます。
